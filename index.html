How we collect the data

The data is collected daily by getting information from the official MIMIT website that gathers data from all fuel stations across Italy and then we process averages of self service prices of gasoline and diesel to provide a representative view of the market over time.

The code behind this

The code is available on GitHub. You can also find the full CSV data of prices there. All data is open and available for use.

Where does this code run?

The code runs on a daily basis to fetch the latest fuel price data on GitHub Actions. It runs automatically at 10:00 AM (UTC) when new data is available.
